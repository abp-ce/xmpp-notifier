# `xmsg`

**Usage**:

```console
$ xmsg [OPTIONS] [ALIAS|RAW_JID] {text}
```

**Arguments**:

* `[ALIAS|RAW_JID]`: Алиас получателя из config.yaml или сырой JID со знаком &#x27;@&#x27;.  [required]
* `text`: Текст сообщения  [required]

**Options**:

* `-p, --profile [default]`: Принудительный выбор бота
* `--install-completion`: Install completion for the current shell.
* `--show-completion`: Show completion for the current shell, to copy it or customize the installation.
* `--help`: Show this message and exit.
